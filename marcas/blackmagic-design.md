# Blackmagic Design

**TL;DR** — fabricante australiana que mudou o preço-base do mercado:
câmeras de cinema, switchers ATEM, conversores, gravadores HyperDeck e o
DaVinci Resolve — com versão gratuita completa o bastante para produção
profissional.

## Onde é forte

| área | produtos |
|---|---|
| câmeras | Pyxis, PYXIS/URSA Cine, Pocket Cinema |
| live | ATEM (do Mini ao Constellation) |
| pós | DaVinci Resolve (edição, cor, Fusion, Fairlight) |
| infraestrutura | conversores Mini, Videohub, HyperDeck |
| codec | [[braw]] |

## Estratégia que importa para orçamento

Vender hardware barato e o software junto (ou de graça) empurra o custo do
fluxo para baixo — mas amarra: a experiência é melhor **dentro** do
[[ecossistema-blackmagic]], e integrar com outros fabricantes às vezes exige
conversor no meio.
