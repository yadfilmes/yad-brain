# ABNT — Associação Brasileira de Normas Técnicas

**TL;DR** — o organismo de normalização técnica do Brasil. Suas normas levam o
prefixo **NBR**. Para audiovisual, a que aparece toda hora é a **NBR 5410**
(instalações elétricas de baixa tensão), que é o chão de qualquer conta de
elétrica de set feita neste acervo.

## O que ela é, e o que ela não é

| |  |
|---|---|
| ABNT | normalização **técnica** — como fazer |
| [[mte]] | normalização **trabalhista** — quem pode fazer, com que treinamento |

As duas incidem sobre o mesmo trabalho por caminhos diferentes: a NBR 5410 diz
como a instalação deve ser; a [[nr-10-eletricidade]] diz quem pode mexer nela.
Cumprir uma não dispensa a outra.

## Normas que este acervo referencia

| norma | assunto | onde aparece |
|---|---|---|
| **NBR 5410** | instalações elétricas de baixa tensão | [[bitola-de-cabo]], [[rede-ac]], [[balanceamento-de-fase]] |

## Gotcha de acesso

**Norma ABNT não é de acesso livre** — o texto integral é vendido. Isso muda
como este acervo pode trabalhar: dá para citar escopo e princípio a partir de
material secundário, mas **não** para reproduzir tabela de capacidade de
condução nem transcrever artigo.

É por isso que a calculadora deste acervo usa valores **conservadores de
propósito** e diz isso na cara: a tabela real da NBR 5410 depende de método de
instalação, agrupamento e temperatura, e não está no repositório.
